동아마라톤 훈련관리 PWA v1.4.0 — 기존 앱 업데이트 전용

중요: 기존 Vercel 프로젝트 ID와 Production URL을 먼저 확인하세요. 이 ZIP은 배포된 상태가 아닙니다.
새 Vercel 프로젝트를 생성하지 말고 기존 프로젝트에 업데이트 배포하세요.
기존 URL, manifest의 name/short_name/start_url/scope, localStorage 키 dongma2027_v1은 유지합니다.
서비스워커 셸 캐시만 v1-4-0으로 변경하며 localStorage/IndexedDB 데이터는 삭제하지 않습니다.

주요 변경
- 9주 준비기: 너리재 오르막·내리막 장거리, 4주차 및 8주차 회복
- 12주 본훈련: 평지 장거리, 후반 MP+10초/MP, 단계적 테이퍼링
- 화요일 VO2max와 일부 주차 연속 변속주(AR) 교대; 목요일 LT 유지·고부하 주차 축소
- 토요일 10km = 10K 기준 +70초/km, 일요일 이지 = 10K 기준 +100초/km
- 준비기 주간 거리 목표 75/80/85/70/85/90/95/80/85km, 수·금 거리 조절
- 주간·월간·전체 21주 각각 PNG 저장 및 모바일 공유 버튼
- 기존 목표 기록, 운동 기록, JSON 백업 구조 유지

사용 방법
1. 기존 앱의 JSON 백업을 먼저 내려받으세요.
2. 기존 Vercel projectId / Production URL / Production 배포 대상인지 확인하세요.
3. ZIP 압축을 풀어 dongma-training-2027 폴더의 정적 파일을 기존 프로젝트에 배포하세요.
4. 기존 Production URL로 접속해 상단 v1.4.0 표시, 주·월·전체 이미지 저장/공유,
   10K+70초 토요일, 너리재→평지 전환, 기존 기록 보존을 확인하세요.
5. 기존 홈 화면 PWA 바로가기가 같은 URL로 실행되는지 확인하세요.

주의
- 훈련 페이스 및 주간 목표는 코칭 초안입니다. 특히 수/금이 20km를 넘는 주는 분할 러닝이나 목표 감량을 고려하세요.
- 여성/남성 풀코스→하프 가변 상수 및 VDOT 50:50 공식은 기존 버전 그대로 유지합니다.
- 외부 공유는 기기 Web Share API 지원 여부에 따라 다릅니다. 지원하지 않으면 PNG 저장 후 갤러리에서 공유하세요.
- 실제 배포, 실기기 PWA 동작, 이미지 공유는 이 ZIP 생성만으로 검증되지 않습니다.
